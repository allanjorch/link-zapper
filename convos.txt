Maybe what we need is focusing in on what we keep, and which situation we are in. So:

1. Determine which platform we are on
2. Determine context:
	2.1. Clean Link
	2.2. Redirect
3. Handle accordingly and copy resulting URL to clipboard

Also - I really want to rename the whole project to "zap-link" instead of "clean-link"

So here's an idea of what the config could look like:

*TEMPLATE

[platform.name]
domains = ["domain1.com", "domain2.com", "domain3.com"]
normalized_domain = "dom1.com"
params = ["keep_param1", "keep_param2"]
redirect_params = ["redirect"]
redirect_services = ["shortener.url"]


Idea being that if a "redirect_service" is detected, use the corresponding function for that platform internally, to get the actual URL. And if a "redirect_param" is detected, use the corresponding reformating function. It's not totally clean yet, but this, I feel, is a good starting point, and we can adjust as we go along. Please read this carefully, and point out if there are any points of conflict at all! And maybe we need to look at precedence here too, if for example the situation arises that there's both a redirection url and param. I don't know if that's even plausible. Just an observation!
